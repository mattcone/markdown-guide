[MarkView](https://markview.io) is a free desktop application for reading Markdown files on macOS, Windows, and Linux. Open a file from the app, drag it onto the window, or use your operating system's Open With command.

It displays tables, code blocks, Mermaid diagrams, and LaTeX equations. It also includes document search, a table of contents, light and dark themes, and printing. No account or document upload is required. The app reads Markdown files without editing them.

MarkView is developed by Doug Kerwin. Official downloads are available from the product website.
