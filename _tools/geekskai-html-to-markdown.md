[Geekskai HTML to Markdown](https://geekskai.com/tools/html-to-markdown/) is a free web tool for converting HTML snippets to Markdown. HTML Code mode can be used without signing in.

Paste an HTML fragment into HTML Code mode, convert it, and review the Markdown output. This can be useful when moving formatted content into Markdown documents.

A basic HTML fragment containing a heading, bold text, a link, a short list, and a JavaScript code block can be converted while preserving those structures in the Markdown output. Review the converted links and formatting before publishing the result.
