[Markitdown Online](https://markitdown.tech/) is a browser-based converter for PDF, DOCX, PPTX, XLSX, HTML, CSV, JSON, XML, images, and public URLs. The generated Markdown can be previewed, edited, copied, or downloaded.

Most supported file conversions run locally in the browser. The built-in editor previews GitHub Flavored Markdown tables, task lists, strikethrough, footnotes, and syntax-highlighted code blocks. It also supports optional math and Mermaid diagram rendering.
